## 🧠 نکات کلیدی ترجمه

- هر آیتم شامل یک فایل `itemXX.md` (متن ترجمه) و یک پکیج مجزا برای کدهای عملی است.
- ترجمه‌ها با رعایت **اصطلاحات فنی استاندارد** و **ساده‌سازی مفاهیم** نگاشته شده‌اند.
- مثال‌های کد، **کاملاً کامنت‌گذاری** شده‌اند تا هم‌راه با توضیحات فارسی، قابل‌درک باشند.

## 🚀 نحوهٔ اجرا و مشارکت

1. پروژه را با Maven یا IDE دلخواه (IntelliJ, Eclipse) باز کنید.
2. هر پکیج شامل یک کلاس `Main` یا `Demo` است که می‌توانید مستقیماً اجرا کنید.
3. اگر علاقه‌مند به مشارکت در ترجمه یا بهبود کدها هستید، خوش‌آمدید!  
   لطفاً ابتدا یک **Issue** باز کنید یا **Pull Request** ارسال نمایید.
