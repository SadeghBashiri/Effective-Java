# 📚 ترجمه فارسی و پیاده‌سازی عملی کتاب Effective Java

این ریپازیتوری با هدف **ترجمه فارسی کتاب Effective Java, 3rd Edition** نوشته‌ی **Joshua Bloch** و ارائه‌ی مثال‌های عملی و قابل اجرا برای مفاهیم آن ایجاد شده است.

هدف پروژه فقط ترجمه‌ی کتاب نیست؛ بلکه تلاش می‌کنیم در کنار ترجمه، مفاهیم مطرح‌شده در کتاب را با **مثال‌های واقعی Java، کدهای قابل اجرا و توضیحات فارسی** بهتر درک و بررسی کنیم.

# 🤖 استفاده از هوش مصنوعی

استفاده از ابزارهای هوش مصنوعی در این پروژه برای **ترجمه اولیه، بازنویسی، بررسی نگارشی و کمک به درک مفاهیم** کاملاً پذیرفته شده است.

می‌توان از ابزارهایی مانند:

* ChatGPT
* Claude
* Gemini
* GitHub Copilot
* و سایر ابزارهای مشابه

استفاده کرد.

اما:

> ⚠️ خروجی AI نباید بدون بازبینی انسانی مستقیماً وارد پروژه شود.

مشارکت‌کننده مسئول کیفیت نهایی محتوایی است که ارسال می‌کند.

قبل از ارسال ترجمه یا Pull Request، موارد زیر باید بررسی شوند:

* متن ترجمه‌شده با متن اصلی مقایسه شود (با استفاده از نسخه PDF اصلی کتاب).
* هیچ جمله، پاراگراف یا مثال مهمی حذف نشده باشد.
* مفهوم اصلی متن تغییر نکرده باشد.
* اصطلاحات تخصصی Java به‌درستی بررسی شده باشند.
* جملات ماشینی و نامفهوم بازنویسی شوند.
* لحن و منظور نویسنده تا حد امکان حفظ شود.
* متن فارسی از نظر نگارشی بررسی شود.
* کدهای ارائه‌شده Compile و در صورت امکان اجرا و آزمایش شوند.

هدف پروژه این نیست که:

```text
English Text → AI → Publish
```

بلکه فرایند موردنظر این است:

```text
Original Text (PDF Reference)
      ↓
AI-assisted Translation
      ↓
Human Review (comparison with PDF)
      ↓
Technical Review
      ↓
Code Verification
      ↓
Final Translation
```

# 🚀 مراحل مشارکت

اگر قصد دارید یک Item جدید را ترجمه یا تکمیل کنید:

### 1. دریافت فایل اصلی کتاب (PDF)

برای دسترسی به متن اصلی و مقایسه ترجمه، از یکی از روش‌های زیر استفاده کنید:
- خرید نسخه رسمی از ناشر
- استفاده از اشتراک کتابخانه دیجیتال
- (در صورت داشتن مجوز) قرار دادن فایل PDF در پوشه `books/`

### 2. بررسی Issues

ابتدا بخش Issues را بررسی کنید و مطمئن شوید Item موردنظر توسط فرد دیگری انتخاب نشده است.

### 3. انتخاب Item

Item موردنظر خود را مشخص کنید.

### 4. اعلام آمادگی

در Issue مربوط به Item کامنت بگذارید و اعلام کنید که قصد انجام آن را دارید.

### 5. Fork

در صورت مشارکت خارج از Repository اصلی، پروژه را Fork کنید.

### 6. ایجاد Branch

برای Item موردنظر یک Branch ایجاد کنید.

### 7. ترجمه و پیاده‌سازی

ترجمه را انجام دهید (با مقایسه مداوم با PDF اصلی) و در صورت نیاز مثال‌های عملی Java را تکمیل یا اصلاح کنید.

### 8. بررسی نهایی

قبل از ارسال Pull Request:

* متن را با نسخه اصلی (PDF) مقایسه کنید.
* ترجمه را کامل بخوانید.
* اصطلاحات تخصصی را بررسی کنید.
* کدها را Compile و در صورت امکان اجرا کنید.
* تغییرات را بررسی کنید.

### 9. ارسال Pull Request

تغییرات را از طریق Pull Request ارسال کنید.

پس از بررسی و اعمال اصلاحات لازم، تغییرات با Branch اصلی پروژه Merge خواهند شد.

# 🌿 نام‌گذاری Branch

برای ترجمه یک Item جدید پیشنهاد می‌شود از الگوی زیر استفاده کنید:

```text
translate/item-01
```

برای اصلاح یک Item موجود:

```text
edit/item-01
```

برای اصلاح کدهای یک Item:

```text
fix/item-01
```

مثال:

```text
translate/item-15
```
